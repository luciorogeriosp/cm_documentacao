# Início / treinamento (módulo CMS)

| Campo | Valor |
| ----- | ----- |
| **Rota** | `/voluntario/mentorias` (Início) — alias `/voluntario/biblioteca` (não é item de menu) |
| **Perfil** | Voluntário (`ativo`) |
| **UCs** | UC73, UC70 |
| **Prioridade** | Especificado |

Treino = **módulo educacional no CMS** (mesmos tipos de atividade do Cliente: videoaula, questionário, download, tarefa, etc.). **Não** é biblioteca avulsa de 3 vídeos.

**Pegar** em Em aberto, inscrever-se em **Ações** e ver coletivas ficam **bloqueados** até o módulo concluído.

Alocação pelo Gestor: o caso **aparece em Minhas** mesmo com treino pendente. Líder só agenda/registra/encerra depois de concluir. Acompanhante vê o card.

```
┌──────────────────────────────────────────────────┐
│  Mentorias                                       │
│  Treino  1/3 atividades                          │
│  [▶] O que é a mentoria                          │
│  [ ] Questionário de alinhamento                 │
│  [ ] Material de apoio                    [PDF]  │
├──────────────────────────────────────────────────┤
│  [ Em aberto ] [ Minhas ] [ Encerradas ]         │
└──────────────────────────────────────────────────┘
```

Enquanto o módulo não termina: Em aberto e Ações mostram aviso + link para Início, sem lista operacional.
