# Série: CMS de Administração

**Público:** equipe do Consulado que **opera** o CMS (programa, edição, módulo, comunicação).  
**Não é** aula de permissões, LGPD, migrar unidade nem desenvolvimento.

**Canônico:** [Casos de Uso v8](../../Casos%20de%20Uso%20-%20Consulado%20da%20Mulher_v8.md). Os roteiros apontam o caso de uso; não o reescrevem.

## Como gravar

Uma reunião longa vira esta playlist. Cada roteiro = um vídeo. Grave na ordem.

- Abertura de todo take: **“CMS modela. Gestor opera. Automação executa. Aplicativo realiza.”**
- No [00](roteiros/00-mapa.md) diga se está na homologação ou no protótipo.
- Textos de WhatsApp: **a revisar** — não invente copy na hora.
- Não mostre senha, CPF nem lista real de empreendedoras.
- Takes em `bruto/` (não vão para o git). Prints em `capturas/`. Links finais em [publicado/README.md](publicado/README.md).

Princípio de cada take: **mostrar a tela, dizer o que faz, dizer o que não faz, dizer o que acontece depois**.
